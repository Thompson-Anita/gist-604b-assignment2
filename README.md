# gist-604b-assignment2
GIST 604B Assignment 2:  QGIS Desktop GIS Projects
Overview
i. This repository demonstrates the ten tutorials that were completed for the second week of GIST 604B Open Source GIS.  The modules documented in this repository cover map making, working with vectors and rasters, table and spatial joins and additional skills.  The tutorials combined with practice in GitHub will help create a consistent practice in using the skills.
ii.  The skills practiced were cartography, understanding QGIS projections, reading and joining attributes, working with the QGIS toolboxes, and importing various file types
Software Environment
i. QGIS Desktop Version 4.2.3
ii. Operating System is Windows 11
iii. QGIS Plug ins used were DB Community, GRASS Processing Provider, MetaSearch Catalog Client, Tool Processing

Reflection
Having never used QGIS previously and only using ESRI products, the new format was a bit of a challenge.  The concepts are the same for the most part, but QGIS has some added tools that had not been part of my previous skill set.  It took a bit to get used to where everything was and how to run the most common tools.  Once everything was a bit more clear, the overall workings of QGIS made more sense. The most challenging parts were how QGIS uses the CRS, making sure files were saved correctly in the project files, and working with the styling tools.  Since this is a learning exercise still, the future use of the skills is two fold.  First is to continue to hone my overall skills in any GIS that I use, and the second is to continue to learn how to efficiently use QGIS.
